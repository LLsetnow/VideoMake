# character 目录规则

本目录按角色保存身份参考图、服装/姿态/场景图和角色音色。每个角色使用独立子目录。

- 角色图使用 `image-gen` 生成并保持身份、发型、服装、配色和构图稳定；人物卡片使用整体 `1:1` 栅格三视图布局。
- 角色口播或台词优先接入对应角色目录中的音色参考文件，不要把其他角色音色接入当前人物。
- 多角色必须使用多个独立参考图和独立 `Load Image` 节点，不能合成为一张图片。
- 接入前确认文件真实存在、格式可读、方向比例和用途正确；不要仅凭文件名猜用途。
- 不覆盖已验证角色资产，不写入凭据。

详细规则见 [`docs/media-assets.md`](../docs/media-assets.md) 与 [`docs/h3.md`](../docs/h3.md)。
