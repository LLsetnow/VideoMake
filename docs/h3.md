# MiniMax H3 Skill、提示词与 T8 节点

## Skill 路由

所有 MiniMax H3 任务先进入项目内的 `minimax-h3-creative-director`。它必须先读取同级 `../minimax-h3-prompt/SKILL.md`，并按任务读取 `reference/VIDEO_PROMPT_WRITING_GUIDE_base_en.md` 或 `reference/VIDEO_PROMPT_WRITING_GUIDE_ref_en.md`。

项目内的 `minimax-h3-prompt` 是格式权威；不要使用全局 `h3-prompt-writing` 替代本项目流程。总导演完成方向确认后只选择一个最终 Skill：

- 无媒体参考的纯文字：`minimax-h3-text-video-prompt`；
- 含人物、物品、场景、风格、动作、镜头或音频参考：`minimax-h3-reference-video-prompt`；
- 明确声明无任何可复用参考职责的纯首帧/首尾帧边界：`minimax-h3-keyframe-video-prompt`；
- 审查已有提示词：`minimax-h3-prompt-reviewer`。

用户明确要求多镜头、分镜、切镜或蒙太奇时，先进入 `minimax-h3-multishot-planner`；视频达到 10 秒且用户未声明单镜头/多镜头时，先询问是否启用多镜头。规划器必须确认镜头数量并逐镜确认，只有 `multishot_plan_status: confirmed` 才能格式化最终提示词。

## 提示词规范

H3 提示词是带时间轴的视听制作简报，不是静态图片描述。描述性字段使用英文，只有对白/歌词 `<d>...</d>` 内的原文和画面中实际出现的文字保留原文。最终同时保存可执行英文提示词和完整中文翻译；中文不得混入英文执行代码块，也不得改写对白、歌词或画面文字。

- 先选择 `T2VA`、`I2VA`、`FL2VA`、`L2VA` 或 Full-reference/`Ref2VA`。
- 基础模式使用 `integrated_multimodal_description`、`overall_soundscape` 和 `non_diegetic_music`。
- I2VA/FL2VA/L2VA 首行写清参考图与目标视频时间点的对齐关系。
- Full-reference 按 `subject_definitions`、`summary`、`retention_analysis`、`detailed_description`、`overall_soundscape`、`non_diegetic_music` 六字段书写。
- `[Shot 1]` 不带时间戳；后续镜头时间戳严格递增并落在目标时长内。镜头运动写成可观察的类型、幅度和速度。
- 对白使用稳定的 `(S1)`、`(S2)` 说话人 ID，原文只放进 `<d>[Language] ...</d>`。
- 环境声和身体/人声非语言声音写入 `overall_soundscape`；角色能听到的现场音乐写入镜头描述；观众专属配乐写入 `non_diegetic_music`。
- 同一参考标签在所有字段中含义一致；严格模式不得引用未接入工作流的媒体标签。人物口播时，角色音色作为对应 `<Audio N>` 输入并与稳定说话人 ID 对齐。

H3 生成边界是素材容器，不是最终剪辑点；提示词 `[Shot]` 只是创作意图。最终切点需经生成后的场景检测、接触表或帧级检查确认。

## `comfyui-minimax-h3-audio-T8`

上游仓库：<https://github.com/T8mars/comfyui-minimax-h3-audio-T8>。节点通常安装在 ComfyUI 的 `custom_nodes/minimax-h3-audio-T8/`，安装或更新后重启 ComfyUI；模型权重使用 ComfyUI 标准模型目录，不复制进项目。节点版本或 ComfyUI 版本变化时，以当前 README、示例 API JSON 和安装版本为准。

重点检查 `MiniMax H3 Audio Conditioning (T8)`：

- `task_type`：按任务使用 `T2VA`、`I2VA`、`FL2VA`、`L2VA`、`Ref2VA`/Full-reference 或 `Hybrid`；
- 每张 Picture、每个 Video、每条 Audio 的实际输入和顺序；
- 锁定源音频、重绘源音频、仅作参考或原生生成等音频模式；
- 提示词参考标签与节点媒体映射；
- `Duration Planner`、`Audio Window`、`AV Decode`、`Output Trim` 等配套节点。

关键约束：固定 24fps，帧数按 `17n+5` 对齐，画布宽高为 32 的倍数，原生 H3 通常 batch size 为 1；引用数量通常不超过 9 张 Picture、3 个 Video 和 3 个独立 Audio。生成前让 Preflight 或等价检查暴露时长、尺寸、显存和输入契约问题。

若使用 `MiniMax H3 Dual-Clock Sampler (T8)`，优先以已验证稳定配置为基线：4 步、`shift_video=12`、`shift_audio=3`、`dual_clock_euler`、`native_flow`。不要在该节点之后重复叠加 Sigma Shift、`KSamplerSelect` 或 `BasicScheduler`；改采样器/调度器时使用节点自身配置并参考上游示例验证。
