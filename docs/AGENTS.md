# docs 目录规则

`docs/` 保存从根 `AGENTS.md` 拆出的长期项目规范、流程说明和可复用知识文档。这里不是视频素材、工作流或最终输出目录。

- 规范文档使用清晰的主题名，例如 `project-workflow.md`、`media-assets.md`、`h3.md`、`aigate.md` 和 `editing-delivery.md`。
- 已有的专题文档（例如 `docs/绝区零.md`）保持原位置；除非用户明确要求，不要覆盖、重命名或清理它们。
- 文档中的命令、路径和 Skill 名称必须与仓库实际结构一致；新增规则时同步更新根 `AGENTS.md` 的索引。
- 文档不得包含 API 密钥、cookies、实例令牌或其他敏感凭据。
- 文档只描述规则和流程，不把生成视频、音频、图片或 workflow JSON 放进这里。
