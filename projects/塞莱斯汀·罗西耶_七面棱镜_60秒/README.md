# 塞莱斯汀·罗西耶｜七面棱镜｜60 秒竖屏视频

## 创作方案

基于奥尔特利亚、维尔米利亚天空圣殿、七枚天穹面、五面棱镜与无构之潮的世界观，制作一支 9:16 竖屏构成主义奇幻短片。

由于 MiniMax H3 单次生成上限为 15 秒，本片拆为四段：

1. **1–15 秒｜圣殿觉醒**：第一束校准光线启动七枚天穹面，塞莱斯汀合成五面棱镜。
2. **16–30 秒｜七向之城**：她穿过朱红圆环，进入维尔米利亚，依次修复道路、边界与变形面。
3. **31–45 秒｜无构之潮**：无构之潮侵入圣殿，世界失去方向；塞莱斯汀发现自己一直在压抑“留白”。
4. **46–60 秒｜第八处留白**：她不再抹平裂缝，而是把裂缝纳入新结构，七枚天穹面形成最终放射构图。
