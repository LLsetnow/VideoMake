# 抽卡视觉效果 30.65 秒

基于 `videoRef/MiniMax H3这个视觉效果谁敢信是一次抽卡..._哔哩哔哩_bilibili.mp4` 的视觉语言分析，生成原创黑/白/猩红哥特拼贴视频。参考视频没有作为 H3 的参考视频输入；仅提取并复用了它的音频。

## 生成约束

- 目标时长：30.650408 秒
- 目标画幅：16:9 横屏，最终导出 1280×720
- H3 分段：0–15 秒、15–30 秒、30–30.650408 秒
- H3 尾段使用 2 秒音频 conditioning，其中后 1.349592 秒为 padding，最终裁掉
- 提示词中的镜头切点均小于 2 秒
- 三个工作流均为文本 + 音频 conditioning，没有视频加载节点，也没有上传 `--video`

## 文件

- `0-15秒/`、`15-30秒/`、`30-30.650408秒/`：各自独立的音频、提示词、工作流和 H3 输出
- `00_素材/`：从参考视频提取的完整音频与三个分段音频
- `01_参考分析/`：源视频及生成结果的抽帧联系表
- `02_提示词/`、`03_工作流/`：集中备份
- `output/抽卡视觉效果_30.650408秒_16x9.mp4`：最终拼接文件

最终拼接阶段裁除 H3 输出的 1280×736 多余高度，统一为 1280×720，并以提取的完整音频重新封装。24 fps 帧量化使容器时长为约 30.666667 秒，音频时长为约 30.650000 秒，差异小于一帧。
