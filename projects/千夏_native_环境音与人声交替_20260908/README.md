# 千夏：native 环境音与人物语音交替测试

本次测试验证 MiniMax H3 `native` 模式能否根据两条普通音频参考，按时间交替生成“只有环境音”和“只有人物语音”的音轨。

- `audio_mode: native`
- 不连接 `drive_audio`
- `ref_audios.ref_audio_0`：纯环境音，雨声/室内底噪/低频嗡鸣
- `ref_audios.ref_audio_1`：纯千夏人声
- `add_source_as_reference: false`
- `prompt_primary_audio_ordinal: 0`
- 不设置 `final_audio`
- 目标时长：5.16 秒

## 目标时间表

| 时间 | 音频目标 |
| --- | --- |
| 00:00.000–00:00.600 | 只有环境音 |
| 00:00.600–00:02.100 | 只有人物第一句 |
| 00:02.100–00:02.700 | 只有环境音 |
| 00:02.700–00:05.160 | 只有人物第二句 |

native 会重新生成音频，不保证严格执行时间切换；最终需用频谱和静音/能量区间检查是否真的分段。

## 本次结果（2026-09-08）

- RH 本地任务：`task_4d5702d44b40`
- 远程任务：`2097252527659909122`
- 消耗：24 coins
- 输出：`output/task_4d5702d44b40/qianxia_native_alternating_ambient_voice_test_1.mp4`
- MP4：736×1280、24 fps、5.166667 秒、H.264 + AAC 32 kHz stereo；ffmpeg 解码通过。
- 画面：角色近景和口型变化正常。
- 音频结论：未按指定时间交替。前 0.68 秒和 0.70–2.33 秒被检测为低于 -40 dB 的静音/近静音区；约 2.33 秒后人声连续出现，没有形成“环境音 → 人声 → 环境音 → 人声”的四段结构。
- 频谱证据：`qa/output_spectrogram.png`；音频分段电平记录在本次测试中，环境段没有形成可辨认的独立环境声层。
- 结论：`native` 可以参考两条音频的音色/质感，但不能可靠地按提示词精确编排短时间的音频开关。若要严格交替，应在 H3 后对音频做时间线剪辑，或直接用预先剪好的 `lock_source` 音频。
