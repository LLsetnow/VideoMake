# 精神创伤｜奇幻梦核平面卡通｜60 秒｜9:16

## 核心概念

一个被通知、会议和“马上要”的消息淹没的短发社畜，在凌晨的办公室里逐渐失去现实边界。她没有突然变成英雄，而是把手机静音、剪断工牌绳，把自己从持续回应的生活里取回来。梦核世界由办公室、纸张、云海、浮动门和会开花的电话组成；结尾不是逃亡，而是一次安静的自我归还。

## 统一视觉约束

- 9:16 竖屏，24 fps，平面 2D/2.5D 卡通，纸张拼贴、硬边色块、轻微印刷颗粒。
- 主角：短黑发齐耳 bob、疲惫眼神、灰蓝宽松衬衫、炭黑百褶裙、红色工牌绳、旧白鞋；全片保持同一张脸、发型、服装和比例。
- 主色：灰蓝、炭黑、雾紫、褪珊瑚、奶油白；自由段增加薄荷绿和浅金色。
- 不使用真实摄影、写实 3D、额外主角、品牌 logo、水印或平台 UI。
