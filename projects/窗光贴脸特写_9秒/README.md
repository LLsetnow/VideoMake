# 窗光贴脸特写

取材于会话中粘贴的中文脚本。以固定机位拍摄一位年轻成年东亚女性的脸部极近特写，表演依次经过移目、闭眼、右转、抬眼、回望和末尾短眨。

## 生成记录

- 使用 OPC CLI 调用 MiniMax H3 文生视频 API，任务 ID `467528520303159`，已完成并下载。
- [生成参数](generation_request.json) · [英文提示词](portrait_prompt.txt) · [中文提示词](portrait_prompt_zh.txt)
- 生成请求为 9 秒、9:16、768P。输入仅使用文字，人物依据文字生成。附件未提供原始视频或音轨，沿用生成的立体声音轨。
- 原片 `output/portrait_raw.mp4` 为 768 × 1344、24 fps、226 帧，[原片探测数据](qa/raw_ffprobe.json)可查。

## 剪辑与验收

- 保留原片第 0 至 221 帧，让结尾停在短眨后半睁、视线刚移向画面右侧的状态。所选片段加速约 2.78%，以 24 fps 输出 216 帧，原生音轨按相同比例调整。
- 原片两侧各裁 6 像素得到 756 × 1344，再缩放至 720 × 1280，保持 9:16。
- [成片](output/窗光贴脸特写_9秒_720x1280.mp4)的视频、双声道 AAC 和容器时长均为 9.000 秒，音画完整解码通过。[成片探测数据](qa/final_ffprobe.json) · [成片接触表](qa/final_contact_sheet.jpg)
- 接触表可见固定机位下的右转、抬眼、回望与末尾短眨。场景检测未检出切点。个别短眨和回转比脚本偏早，面颊小痣从开场即可见。
