### subject_definitions
- 对象定义
```text
<Subject 1>: 人物面部身份参考。用于锁定[角色名]的脸型、五官比例、眼睛形状与颜色、眉形、鼻唇特征、肤色、发际线和发型轮廓。保持人物面部身份一致，不继承该参考图中的背景、服装或身体姿势。

<Subject 2>: 人物身体结构参考。用于锁定[角色名]的身高比例、肩宽、腰胯比例、体型、四肢长度，以及[重点身体部位，例如手臂、手部、腿部或肩颈]的形态和解剖比例。保持身体结构稳定，不将该参考图的面部或服装作为主要参考。

<Subject 3>（动作与姿势参考）：用于参考Yudii行走时的身体重心、步幅、肩部摆动、持手机时的手臂角度、手腕姿态和自然手势。该参考仅用于动作与姿势，不继承参考图中的人物面部、身体比例、服装、手机外观或背景环境。

<Subject 4>: 人物服装与配饰参考。用于锁定[服装名称]的款式、颜色、材质、剪裁、层次、纹理、图案、鞋子和配饰。保持服装设计与关键细节一致，不继承该参考图中的人物面部、身体姿势或背景。

<Subject 5>: 背景与空间环境参考。用于锁定[场景名称]的空间结构、建筑或自然元素、前中后景关系、主要色彩、材质、光源方向和环境细节。保持背景的整体布局与视觉风格一致，但允许根据镜头运动调整透视和景别。

<Audio 1>: 参考音乐。用于参考或复用[音乐名称/音乐类型]的节奏、速度、乐器编制、鼓点结构、旋律走向和段落变化。

<Audio 2>（角色参考音色，对应说话人 S1）：用于确定该角色的音色、音高、年龄感、气息、语速、发音方式和说话节奏。只参考声音特征，不复制原音频中的台词内容。
```

### summary
- 任务综述
`任务类型 + 各标签职责 + 总体保留目标 + 音频使用方式`

```
summary:
综合使用 `<Subject 1>` 的面部、`<Subject 2>` 的身体结构、`<Subject 3>` 的服装、`<Subject 4>` 的背景，生成一个统一连贯的单角色视频。保持人物身份、身体比例、服装细节以及人物与背景之间的空间关系。音乐 `<Audio 1>` 只参考节奏、乐器、速度和结构。并使用<Audio 2>作为该角色（S1）的参考音色。保持人物视觉身份一致，参考<Audio 2>的音色、音高、气息和语速，但重新生成新的对白，不直接复制原音频内容
```


###  retention_analysis
- 留存分析

- 音频
```text
retention_analysis:
<Audio 1>: fully_copy——整首原曲原样作为视频完整音轨

<Audio 1>：reference——只参考音乐的节奏、速度、乐器编制和段落结构，不直接复制原始音频信号

<Audio 1>：partially_copy——使用原曲前 20 秒，同时加入对白和环境声
```


- 图像
```text
retention_analysis:
<Subject 1>（人物面部身份；出现在[Shot 1]、[Shot 2]和[Shot 3]）：fully_preserved——完整保留人物的面部身份以及关键五官特征，使人物在整个视频中保持一致。

<Subject 2>（人物身体结构；出现在[Shot 1]、[Shot 2]和[Shot 3]）：fully_preserved——完整保留人物的身体比例、体型和指定身体部位的形态。

<Subject 3>（人物服装与配饰；出现在[Shot 1]、[Shot 2]和[Shot 3]）：fully_preserved——完整保留服装的款式、颜色、材质、纹理、剪裁和配饰细节。

<Subject 4>（背景环境；出现在[Shot 1]、[Shot 2]和[Shot 3]）：fully_preserved——保留背景的主要空间结构、布局、光源方向、色彩和环境特征。

<Audio 1>（背景音乐）：reference——只参考音乐的节奏、速度、乐器编制和段落结构，不直接复制原始音频信号。


```

### detailed_description

- `[Shot 1]` 不写时间戳，默认从 `0.000` 秒开始。
- 从 `[Shot 2]` 开始写时间。
- 时间必须严格递增。
- 使用三位毫秒，例如 `00:03.500`。
- 时间点必须在视频总时长以内。
- 只有发生新镜头、新空间、新状态或新视角时才使用新 Shot；普通推近、摇镜、环绕应继续写在当前 Shot 内。

```
detailed_description:

[Shot 1] 人物站在窗边，镜头缓慢推近人物面部。

[Shot 2] 在00:03.000时，镜头切换到人物双手的特写。人物慢慢打开一封旧信。

[Shot 3] 在00:06.500时，镜头切换到越肩视角。人物望向窗外的雨街。
```

- 台词
	- `<Audio 2>` 是音色参考，不是背景音乐。
	- 同一角色始终使用 `(S1)`。
	- 新对白放入 `<d>[中文]……</d>`。
	- 参考音频中的原台词不要自动复制。
	- `retention_analysis` 中不要写 `(S1)`。
	- 如果是直接使用原始语音，而不是模仿音色，才改用 `fully_copy` 或 `partially_copy`。

```text
[Shot 1] 角色（S1）使用参考<Audio 2>的清晰、略带气息且语速平稳的声音说：<d>[中文]我们出发吧。</d>
[Shot 2] 同一角色（S1）保持与<Audio 2>一致的音色和说话方式，说：<d>[中文]这里的风景真漂亮。</d>`
```

### overall_soundscape
- 景观声音（音效）
- 整段视频的环境声、动作声和非语言人声

```text
overall_soundscape:

安静的室内环境底噪和轻微的通风声贯穿全片。角色移动时有轻微脚步声、衣物摩擦声和手部触碰物体的细小声音。角色说话时保留自然呼吸声，但不包含具体对白内容。

户外森林：轻风、树叶摩擦声、远处鸟鸣和脚步声。
城市街道：远处车辆声、人群低语、鞋底踩过地面的声音。
雨天房间：雨滴敲窗声、低沉室内底噪和衣物摩擦声。
```
- 只有完全没有环境声、动作声和非语言人声时，才写：`overall_soundscape: N/A`

### non_diegetic_music
- BGM 背景配乐
- 乐器 + 速度 + 节奏 + 动态变化

```
non_diegetic_music:

观众听到稀疏的钢琴和持续的低音弦乐。音乐采用缓慢速度和轻微脉冲节奏，整体音量较低，并在最后几秒逐渐增强。
```

如果使用参考音乐 `<Audio 1>`，但不直接复制：

```
non_diegetic_music: <Audio 1> is used as a reference for a sparse piano-and-string score with a slow tempo, a gentle pulse, and gradual dynamic growth. The target music is newly generated and does not copy the original recording.
```

如果完整复用参考音乐：

```
non_diegetic_music: <Audio 1> is directly reused as the complete audience-only score.
```

如果没有观众配乐：

```
non_diegetic_music: N/A
```
